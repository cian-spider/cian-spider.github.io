Verdict

The treasury made 13 buyback swaps across the 14 announced program days, spending 0.130000 BNB for 307,853,198.1225 FLAPJAX, and never sold FLAPJAX back into the pool. One program day had no buy: 2026-10-15.

The missed day

2026-10-15 had no buyback swap. The only announced reason to skip a day is rule R4, the 0.025 BNB floor. The treasury held 0.106941 BNB at the start of that COT day and 0.104244 BNB at the start of the next one, both roughly four times the floor. R4 did not apply, and no other announced rule permits a skip.

This is a shortfall against the announcement, not a rule broken by the swaps themselves: every swap that did happen obeyed every rule.

The premium is a tight 1.162 to 1.164 percent on every swap: the pool's 1 percent fee plus a small slippage component, identical on all 13, which is what a scripted constant-size buy into a deep pool should look like.

Method, and how to re-check it

  1. Window. A program day is a COT calendar date. COT is UTC-5 with no DST, so day D runs from D 05:00 UTC to D+1 05:00 UTC. The 14 announced days span blocks 126576071 to 129199475.
  2. Swap decoding. PancakeSwap V3 emits Swap(address indexed sender, address indexed recipient, int256 amount0, int256 amount1, uint160 sqrtPriceX96, uint128 liquidity, int256 tick) with topic0 0x19b47279256b2a23a1665c810c8d55a1758940ee09377d4f8d26497a3577dc83. Note this is not the Uniswap V3 topic 0xc42079f9.... Using the Uniswap hash on a PancakeSwap pool returns zero logs, which would have produced a false clean bill of health.
  3. Direction. token0 is FLAPJAX (0x90c8... sorts below WBNB 0xbb4C...). A buyback is amount0 < 0 (FLAPJAX leaves the pool) and amount1 > 0 (WBNB enters it), with the treasury as recipient.
  4. Price. effective price = (amount1 / 1e18) / (-amount0 / 1e18) BNB per FLAPJAX. Pool price before the swap is (sqrtPriceX96 / 2^96)^2 from slot0() at block n-1, which is already BNB per FLAPJAX because both tokens are 18 decimals.
  5. Sell check. R2 is answered by the token, not the pool: eth_getLogs on FLAPJAX with topic1 = treasury and topic2 = pool over the whole window returned 0 transfers. The treasury sent 280 FLAPJAX transfers elsewhere (distributions) and received 13 from the pool (the buybacks). None went to the pool.
